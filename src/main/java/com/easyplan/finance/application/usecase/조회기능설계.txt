이제 집계 기능이 매우 많아질텐데 나눠보자.

- SummaryReader
1. 순 자산
2. 총 자산
3. 총 부채
4. 월별 수입 / 지출

- AccountBalanceReader
1. 계정별 잔액 (1)
2. 계정 타입별 잔액 (N)
3. 자산 계정 목록과 자산 계정 잔액
4. 부채 계정 목록과 부채 계정 금액

- JournalHistoryReader
1. 최근 거래 목록			( 페이징 O )
2. 거래 상세 조회
3. 거래 검색 / 필터링 ( 페이징 O )
4. 월별 거래 목록     ( 페이징 O )

- CategoryStatsRea
1. 계정 항목 별 지출 합계
2. 계정 항목 별 수입 합계
3. 지출 TOP 5

- ReportReader
1. 월별 수입/지출 추이
2. 월별 순자산 추이
3. 최근 6개월 지출 변화
